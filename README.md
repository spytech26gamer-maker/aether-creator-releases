# ÆTHER CREATOR downloads

ÆTHER CREATOR is a desktop studio for YouTube creators: ÆVA writes your titles and descriptions, makes subtitles,
translates them into 150+ languages, dubs the voice, cuts vertical Shorts and uploads everything to YouTube.

**Get the latest version:** [Releases → Latest](https://github.com/spytech26gamer-maker/aether-creator-releases/releases/latest)

| Computer | File |
|---|---|
| Mac (Apple Silicon, M1 and newer) | `AETHER-CREATOR-x.y.z-mac-arm64.dmg` |
| Windows 10 / 11 (64-bit) | `AETHER-CREATOR-Setup-x.y.z.exe` |

**Mac:** open the .dmg and drag ÆTHER CREATOR into Applications. The first time, right-click the app and choose Open.

**Windows:** run the setup. If Windows says "Windows protected your PC", click More info, then Run anyway.

Once installed, the app checks this page by itself and shows "New update available" when there is a new version.
